# Karaoke Contest

Installers for **Karaoke Contest**, the party game where the audience rates the singers from their phones.

## Download

**[Get the latest release](https://github.com/aaronortiz/party-voting-releases/releases/latest)**, then download:

- **Windows:** `Karaoke-Contest-Setup-<version>.exe`
- **Mac** (Apple silicon): `Karaoke-Contest-<version>-arm64.dmg`

## Install

1. Run the installer. It isn't signed yet, so each machine shows a one-time warning: on Windows, **More info → Run anyway**; on a Mac, **System Settings → Privacy & Security → Open Anyway**.
2. Start **Karaoke Contest**. Its window is the console; closing it shuts the game down.

The version you're running shows at the bottom of **Settings…**.

## Updates

- **Windows** keeps itself up to date: when it starts, it downloads a newer version in the background and installs it when you close the program.
- **Mac** shows "Version … is available" in **Settings…**, with a link here; download and install it by hand.
- A copy whose version is a date, such as `2026.11.12`, can't update to the numbered versions: install the latest once by hand, and it updates itself from then on.
